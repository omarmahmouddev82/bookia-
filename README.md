### Tech Stack & Features 🛠️
- **Flutter & Dart** - Cross-platform mobile development.
- **State Management** - Flutter Bloc (`Cubit`).
- **Localization** - `easy_localization` for Arabic and English support.
- **Responsive Design** - `flutter_screenutil` for perfect scaling across all devices.
- **Routing** - Named routing system with custom `AppRouter`.
- **Custom UI System** - Reusable components (`AppButton`, custom text styles, and theme configurations).
